
= Numeric

Numeric values state a plain number with no associated unit of measure or currency. Numeric is
different from Quantity in that no unit of measure is given, and different from Percentage in
that the value is not a fraction of a hundred.

In EHF CV, Numeric is used for counts such as a number of years of experience.

====
IMPORTANT:  No restriction on number of decimals for numeric values.
